# 리센느 포카 교환기

현재 버전은 닉네임·4자리 PIN 로그인, 관리자 공용 도감, 보유 포카별 교환 후보, 1장 단위 약속 교환을 지원합니다. 서버 적용 및 관리자 지정은 [SPEC_SETUP.md](supabase/SPEC_SETUP.md)를 참고하세요. 아래 내용은 이전 BETA 2의 실행·배포 구조 기록이며, 최신 기능 기준은 [명세서](RESCENE_SWAP_SPEC.md)입니다.

## BETA 2 기록

같은 날짜에 참여한 사람들이 공용 도감에서 내놓을 포카와 원하는 포카를 골라 교환하는 모바일 웹입니다.

배포 주소: https://cjy00852.github.io/poca_swap/

## 이용 흐름

- 도감에서 행사·종류·멤버로 검색하고 내놓아요와 구해요를 선택합니다. 두 목록 모두 같은 도감을 사용하며 각각 30종, 종류별 1~99장을 설정할 수 있습니다.
- 사진을 추가하면 행사·종류·멤버·이름과 함께 공용 도감에 영구 저장됩니다. 다른 사용자도 선택할 수 있고, 선택할 때 이름을 다시 입력하지 않습니다. 같은 분류와 이름의 중복 등록은 막습니다.
- 기존 기기에 저장된 사진은 ‘이전에 저장한 내 사진’에서 분류를 입력하고 직접 도감에 추가할 수 있습니다. 기존 개인 사진을 자동 공개하지 않습니다.
- 닉네임과 날짜를 정해 참여하고 선택한 목록을 게시합니다. 닉네임은 전체 사용자 사이에서 중복되지 않으며 띄어쓰기와 영문 대소문자 차이도 동일하게 취급합니다.
- 같은 날짜에서 서로 원하는 도감 포카가 맞으면 실시간으로 매칭됩니다. 한 사람이 수량을 정해 완료 요청을 보내고 상대가 확인하면 양쪽 목록에서 해당 수량만 차감합니다. 0장이 된 항목만 없어집니다.
- ‘여기 있어요’는 검은 배경, 큰 분홍색 닉네임, 보유 포카 사진 한 장을 표시합니다. 좌우 버튼이나 스와이프로 넘깁니다.
- ‘나가기’는 게시 목록과 진행 중인 요청을 철회합니다. 공용 도감, 닉네임, 완료 거래 내역은 유지됩니다. 창을 닫는 것만으로 나가지는 않습니다.

## 개발 및 검증

Node.js 22 이상과 pnpm을 사용합니다.

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
# 개발 서버가 실행 중이고 Chrome이 설치된 상태:
pnpm test:browser
```

DB 테스트는 실제 SQL을 PGlite에서 실행해 권한, 닉네임 중복, 도감 식별, 수량 검증, 부분 교환, 오래된 수정 요청 거절, 기존 거래 내역 보존을 검사합니다. 브라우저 테스트는 두 독립 세션에서 도감 추가·선택, 교환 수량, 전체 화면 사진 넘김, 나가기 및 모바일 화면을 확인합니다.

실제 Supabase에서도 두 익명 사용자의 매칭, 부분 교환, 내역, 나가기, Realtime 알림을 검증했습니다. 테스트 사용자는 참여를 종료했습니다.

## Supabase와 배포

현재 Supabase 프로젝트는 `pksgjcpeqgbfejxagiev`입니다. 새 프로젝트를 연결할 때만 다음 순서로 설정합니다.

1. Anonymous Sign-Ins를 활성화합니다.
2. `supabase/schema.sql`을 한 번 실행합니다.
3. `supabase/migrations/002_shared_catalog.sql`을 한 번 실행합니다. 기존 프로젝트에는 3번만 적용합니다. 반복 실행용 SQL이 아닙니다.
4. `.env.example`을 `.env.local`로 복사해 프로젝트 URL과 공개 publishable 키를 입력합니다.

```dotenv
VITE_SUPABASE_URL=https://프로젝트ID.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=공개용키
```

`main`에 푸시하면 GitHub Actions가 DB 테스트와 빌드 후 GitHub Pages에 배포합니다. Pages Source는 GitHub Actions입니다. `.env.production`은 브라우저 공개용 연결 정보만 포함합니다. 비밀키는 사용하지 않습니다.

사진은 비공개 버킷에 저장합니다. 공용 도감에 명시적으로 추가한 사진만 모든 로그인 사용자에게 읽기를 허용하며, 만료되는 서명 URL로 표시합니다. 권한 및 수량 처리와 동시 수정 검증은 서버에서 수행합니다. 실시간 알림 외에 활성 화면에서 15초 간격으로 새로고침합니다.

## 저장 범위

익명 계정이므로 같은 브라우저의 로그인 정보를 유지해야 거래 내역과 닉네임을 다시 사용할 수 있습니다. 브라우저 데이터를 삭제하거나 기기를 바꾸면 현재는 계정 복구가 불가능합니다.

날짜가 같은 사용자는 같은 교환 공간에 참여합니다. 위치나 행사장 인증은 하지 않습니다. 도감과 완료 내역은 서버에 남고, 개인 선택 초안은 기기에 저장합니다. 기본 사진 다섯 장은 ‘기존 포카 / 미분류’로 제공됩니다.
